# 嵌入式 AI 环境配置指引

本 skill 只做指引：告诉用户需要什么、从哪里获取。安装由用户按官方说明自己完成。用户请你帮忙装某一项时，按那个工具的官方文档操作，装完用官方给的命令确认能运行。

## 步骤

1. **提示准备知识库。** 读 [knowledge-base.md](knowledge-base.md)，用几句话告诉用户：AI 能帮到什么程度，取决于它能读到的资料；列出要准备的资料和整理方法。问用户资料放在哪里、整理到了哪一步。这一步只提示，不替用户整理。
2. **列出工具清单。** 读 [tools.md](tools.md)，按类别列出每一项能让 AI 做什么。推荐全部，问用户要哪些；用户手头没有对应硬件的（例如数控电源、总线工具、逻辑分析仪），可以跳过。
3. **给出获取方式。** 对用户选中的每一项，给出 `tools.md` 里的官方地址，并标出要用户本人做的事：购买硬件、申请软件许可证、用管理员权限安装、接线。
4. **汇总。** 列出用户选中的工具和地址。提醒用户装好以后，在项目说明文件（Claude Code 读 `CLAUDE.md`，Codex 等读 `AGENTS.md`）里写明资料位置、工具位置和常用命令，以后的会话就能直接使用。

用户问到清单以外的工具时，按 `tools.md` 开头的四条标准判断它对 AI 是否友好，再给建议。
